# MODEL DOWNLOAD & SETUP GUIDE

1. Text Embedding Model: BAAI/bge-large-en-v1.5 (1024-dim)
------------------------------------------------------------
python -c "from transformers import AutoTokenizer, AutoModel; AutoTokenizer.from_pretrained('BAAI/bge-large-en-v1.5'); AutoModel.from_pretrained('BAAI/bge-large-en-v1.5')"


2. Cross-Modal Reranking Model: openai/clip-vit-base-patch32 (512-dim)
----------------------------------------------------------------------
python -c "from transformers import CLIPProcessor, CLIPModel; CLIPProcessor.from_pretrained('openai/clip-vit-base-patch32'); CLIPModel.from_pretrained('openai/clip-vit-base-patch32')"


3. Query Intent Normalization Model: Qwen/Qwen2.5-0.5B-Instruct
----------------------------------------------------------------
python -c "from transformers import AutoModelForCausalLM, AutoTokenizer; AutoTokenizer.from_pretrained('Qwen/Qwen2.5-0.5B-Instruct'); AutoModelForCausalLM.from_pretrained('Qwen/Qwen2.5-0.5B-Instruct')"

Note: The fine-tuned e-commerce LoRA adapter weights are already included in:
models/qwen_0.5b_ecommerce_lora/


4. Vision-Language Captioning Model: Qwen/Qwen2-VL-2B-Instruct (Optional for offline ingestion)
------------------------------------------------------------------------------------------------
python -c "from transformers import Qwen2VLForConditionalGeneration, AutoProcessor; AutoProcessor.from_pretrained('Qwen/Qwen2-VL-2B-Instruct'); Qwen2VLForConditionalGeneration.from_pretrained('Qwen/Qwen2-VL-2B-Instruct')"
